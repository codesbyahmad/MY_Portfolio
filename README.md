# Personal Portfolio Website

![Portfolio Preview](https://img.shields.io/badge/Live-Demo-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

A responsive personal portfolio website built to showcase software development projects, academic coursework, and technical capabilities in Artificial Intelligence and Robotics.

🌐 **Live Demo:** [https://codesbyahmad.github.io/MY_Portfolio/](https://codesbyahmad.github.io/MY_Portfolio/)

---

## 🚀 Key Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewports.
- **Project Showcase:** Highlights key applications, including FinWise AI and MedGuide AI.
- **Interactive UI:** Smooth navigation, dynamic typing animations, and custom UI components.
- **Core Skills Highlight:** Features expertise across Python development, AI frameworks, kinematics, and digital logic systems.

---

## 🛠️ Built With

- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **Bootstrap 5**
- **TypeIt.js / GSAP / Swiper**
- **FontAwesome & Themify Icons**
